# 早餐餐饮静态官网
> 基于原生HTML+CSS+JavaScript开发的多页面静态展示网站，适合前端入门实训项目。

## ✨项目介绍
本项目是面向早餐餐饮的企业展示官网，采用多页面分层架构，不依赖第三方前端框架，全部样式与交互手写实现。
实现企业官网常见核心功能：导航菜单、轮播图、图文产品展示、媒体预览、登录页面等。

## 🛠️技术栈
- HTML5：页面结构搭建，多页面划分
- CSS3：页面布局、样式美化、响应式适配
- JavaScript：页面交互效果、轮播、表单简单逻辑

## 📁项目目录结构
breakfast_food_website
├── css          # 样式文件
├── images       # 项目图片资源
├── js           # javascript 交互脚本

├── index.html   # 网站首页
└── login.html   # 登录页面
